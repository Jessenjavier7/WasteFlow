Smart Waste Management System

Aplikasi pengelolaan sampah berbasis teknologi yang terdiri dari tiga
komponen utama:

    Website --- dashboard dan pengelolaan laporan untuk
    admin/pengguna.
    Mobile --- aplikasi pengguna untuk membuat laporan sampah,
    mengunggah foto, dan melihat hasil prediksi.
    ML Service --- REST API berbasis FastAPI untuk memprediksi
    kategori sampah dari gambar.
